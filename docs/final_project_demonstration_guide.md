# Final Project Demonstration Guide

**Project:** Retail Customer Behavior & Shopping Trends Analytics Web Application  
**Sprint:** Sprint 006 – Testing & Final Delivery  
**Task:** Task 010 – Prepare Final Project Demonstration  
**Owner:** Santosh K Naik

## 1. Demonstration Objective

Demonstrate the completed retail analytics application using the retail dataset. Present the main workflow, analytical features, downloadable reports, and project documentation for company evaluation.

## 2. Demonstration Sequence

1. **Application startup:** Start the FastAPI backend and React frontend and verify that both are accessible.
2. **CSV upload:** Upload the retail dataset and show the upload response and dataset preview.
3. **Data quality:** Explain missing values, validation results, and dataset quality information.
4. **Data cleaning:** Demonstrate the available cleaning options and review the cleaning summary.
5. **Dashboard:** Present KPI cards, interactive charts, and available filters.
6. **Customer analytics:** Show customer age, gender, and location distributions.
7. **Shopping patterns:** Present supported product, category, purchase amount, and purchasing-behavior summaries.
8. **Reports and exports:** Demonstrate PDF report generation and CSV downloads, where implemented.
9. **Error handling:** Show how the application handles invalid uploads and empty results.
10. **Project handover:** Review the README, technical documentation, repository structure, and setup instructions.

## 3. Dataset Notes

The retail dataset used during development contains approximately 3,900 records and 18 columns. The `Review Rating` column has been reported to contain missing values.

The dataset does not contain a transaction-date column. Do not present chronological transaction trends as a supported feature.
